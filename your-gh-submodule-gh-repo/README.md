# Your GH Submodule GH Repo

This is a placeholder directory that replaces the MoL-blog-content submodule.

## Structure

- `posts/` - Contains markdown blog posts
- `example-content/` - Contains example content
- `package.json` - Package configuration
- `pipeline.ts` - Content pipeline script

## Usage

Replace this directory with your actual GitHub submodule by:

1. Adding your submodule: `git submodule add <your-repo-url> your-gh-submodule-gh-repo`
2. Updating the paths in the project configuration
3. Running `pnpm install` to install dependencies
